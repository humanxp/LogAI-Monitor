About Filters

Filters allow you to monitor specific log patterns and receive alerts when they match. You can:

  • Filter by Severity: Match logs with specific severity levels (error, warning, etc.)
  • Filter by Source: Match logs from specific sources or containers
  • Filter by Message: Match logs containing specific text or regex patterns
  • Telegram Notifications: Receive alerts via Telegram when filters match

When a filter matches an incoming log, an alert is created and optionally sent to Telegram with AI-generated analysis.
