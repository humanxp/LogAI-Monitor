Docker Log Collection

LogAI Monitor automatically collects logs from all running Docker containers. Features:

  • Auto-discovery: New containers are automatically detected and monitored
  • Real-time streaming: Logs are collected in real-time as they're generated
  • Severity detection: Log severity is automatically detected from message content
  • Filter support: Create filters to alert on specific container events

Make sure the Docker socket is mounted for log collection to work.
